# 👋 Lesson 1: First Pybricks Program

This lesson introduces the basic structure of a text-based Pybricks program.

The program:

* Prints messages in the output console
* Creates a motor object
* Runs the motor forward
* Stops the motor
* Runs the motor backward
* Stops and ends the program

## 📁 Files

* `simulator.py` — runs in the GearsBot simulator
* `actual.py` — runs on an actual SPIKE Prime robot

## 🧠 Concepts Introduced

* Importing Pybricks classes and tools
* Selecting a motor port
* Creating a `Motor` object
* Using `print()`
* Using `motor.run()`
* Using `motor.stop()`
* Using `wait()`
* Using positive and negative motor speeds

## ▶️ Running the Simulator Version

1. Open the [GearsBot Simulator](https://gears.aposteriori.com.sg/).
2. Select a robot with a motor connected to Port A.
3. Open the Python editor.
4. Copy and paste the contents of `simulator.py`.
5. Run the program.

## 🧱 Running the Actual Version

1. Connect a motor to Port A of the SPIKE Prime hub.
2. Open [Pybricks Code](https://code.pybricks.com/).
3. Connect the SPIKE Prime hub.
4. Copy and paste the contents of `actual.py`.
5. Run the program.

> Lift the robot or motor mechanism before the first test so it can rotate safely.

## 🧪 Try It Yourself

Modify the program to:

* Increase or decrease the motor speed
* Change how long the motor runs
* Add a longer pause between movements
* Make the motor rotate backward first
