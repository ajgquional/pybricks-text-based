# ⚙️ Lesson 2: Motor Control

This lesson explores different ways to control a single motor using text-based Pybricks.

The program demonstrates:

* Running a motor at different speeds
* Rotating the motor forward and backward
* Stopping the motor manually
* Rotating the motor by a specific angle
* Using constants for speed and timing values

## 📁 Files

* `simulator.py` — runs in the GearsBot simulator
* `actual.py` — runs on an actual SPIKE Prime robot

## 🧠 Concepts Introduced

* `motor.run()`
* `motor.stop()`
* `motor.run_angle()`
* Positive and negative motor speeds
* Degrees per second
* Motor rotation angles
* Constants
* Timed motor movement

## ▶️ Running the Simulator Version

1. Open the [GearsBot Simulator](https://gears.aposteriori.com.sg/).
2. Select a robot with a motor connected to Port A.
3. Open the Python editor.
4. Copy and paste the contents of `simulator.py`.
5. Run the program.

## 🧱 Running the Actual Version

1. Connect a motor to Port A of the SPIKE Prime hub.
2. Open [Pybricks Code](https://code.pybricks.com/).
3. Connect the SPIKE Prime hub.
4. Copy and paste the contents of `actual.py`.
5. Run the program.

> Make sure the motor and any attached mechanism can rotate safely before running the code.

## 🧪 Try It Yourself

Modify the program to:

* Use three different motor speeds
* Change the running time
* Rotate the motor by 90 degrees
* Rotate the motor by two complete revolutions
* Change the order of the motor actions
